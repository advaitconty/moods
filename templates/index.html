Moods Music Player

Simple API to play music with minimal friction, right when you need it.

Have you ever felt down one day and wanted the least amount of friction in your room to start playing music? Well, introducing Moods, your best friend for this!

It runs on a couple basic GET and POST requests to help play music directly on your PC. There is also a mobile app (refer to the mobile_apps folder for code) which is basically a set of simple buttons.

It's very adaptable, and picks up all the MP3s you have of your favourite songs!

GET /pause

Will pause the song that is currently playing

Success:

{
    "message": "Paused playback"
}

Error:

{
    "error": "No song is currently playing"
}

GET /resume

Will resume the currently playing song

Success:

{
    "message": "Resumed playback"
}

Failure:

{
    "error": "No song is currently paused"
}

GET /stop

Will stop the currently playing song

Success:

{
    "message": "Stopped playback"
}

Failure:

{
    "error": "No song is currently playing"
}

POST /play

Accepts a JSON of what is to be played, can be a playlist or a song

Input for Playlist:

{
    "key": "somepassword",
    "playlist": "relax"
}

Input for Song:

{
    "key": "somepassword",
    "song": "BoyWithUke - Burn"
}

POST /play-with-mood

⚠️ Warning

This is only available if you have set up your Claude/Anthropic API key in api_key.py

Accepts a JSON with a custom mood or vibe the user wants to play and Claude will select the song to play

Input:

{
    "key": "somepassword",
    "mood": "happy"
}

Adapting it to be your own

Being the adaptable bunch it is, it has been designed to run on lower-end hardware (a Raspberry Pi Zero 2 W).

To get started on making this your own, you'll need to set up the config.py file for use in your own one:

MUSIC_DIR = "/Users/conytadvait/Music" 
# Without the / at the end else it won't work!

KEY = "something" 
# For security reasons, so your friends can't just randomly POST to it!

# Not required but up to you!
PLAYLISTS = {"wind down": ["C418 - Minecraft.mp3", 
                          "C418 - Sweden.mp3", 
                          "C418 - Mice On Venus.mp3",
                          "C418 - Subwoofer Lullaby.mp3",
                          "C418 - Wet Hands.mp3",
                          "C418 - Haggstrom.mp3"],
            "relax": ["BoyWithUke - I Wish.mp3",
                      "BoyWithUke - Animal Crackers.mp3",
                      "BoyWithUke - Nightmare.mp3",
                      "BoyWithUke - Blurry Nights.mp3"]}

Finally, if you want to set up the mobile app to your own server, just change the server and password in settings!
